# First physical checks for the expanded library

For a complete saved design, use **Parts → Physical test pack**. It exports exact placements, instructions, BOM, bags, artifact hash (for cloud builds), source/admission evidence and a pending checklist. Record every result against that exact model and instruction pace. No test result is prefilled as passed.

The software work does not require the user's help. Physical fit and handling cannot be established from LDraw surfaces, so this is the next useful contribution before launch. Existing pieces in any recorded source color are sufficient; no buying flow or kit ordering is required.

Use gentle ordinary building force. Stop if a fit needs force, bends unexpectedly, stresses plastic, or appears to involve the wrong connection type. These experiments are not production instructions.

| Test | Pieces | What to record |
| --- | --- | --- |
| Baseline stud/clutch | 3005 brick and 3024 plate | Seating, normal grip, removal, wobble |
| Long plate/tile support | 3008 brick and 2431 tile | Flat seating over the stud row, seam alignment, rocking |
| Sideways detailing | 87087 side-stud brick and 3024 plate | Recess clearance, orientation, grip, removal |
| Arch cap | 92950 raised arch and 3024 plate | Stud fit and handling of the supported cap |
| Open-tube curved mounting | 47457 curved slope and a 3005 brick or 3024 plate | Fit at the explicit central underside tube mouth; whether the nominal tube fit actually grips |
| Plant mounting | 4728 flower and a 3005 brick or 3024 plate | Actual lower tube fit, orientation, clutch and handling |
| Existing manual pane fit | 60592 frame and 60601 pane | Correct orientation, tab seating, installation sequence, stress and retention |

For each test, record the exact part IDs and mould variant, reference part, orientation, installed/separated photos, and pass/fail notes. Test more than one sample if possible; age, wear and mould differences matter. A successful pair test is not proof of an entire structure.

After these pairs, physically build the reusable wall, arch, side detail, plant and curved examples, then representative complete demo models. Record instruction ambiguities, insertion access, falling/loose components and support failures. Update only the tested scope with the actual evidence and date; keep untested combinations marked as untested.
